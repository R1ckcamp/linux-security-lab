# Linux Security Lab

Laboratório prático de hardening e segurança Linux.

## Tecnologias

- Linux Ubuntu
- UFW Firewall
- Fail2Ban
- SSH Hardening
- Bash Script

## Objetivos

- Melhorar segurança do sistema
- Automatizar hardening
- Aprender administração Linux
- Simular ambiente corporativo

## Funcionalidades

- Configuração automática de firewall
- Proteção contra brute force
- Hardening SSH
- Atualizações automáticas
- Scripts de auditoria

## Como executar

```bash
chmod +x scripts/hardening.sh
./scripts/hardening.sh
